**InfiniteWeb** — приложение для визуального изучения структуры проекта. Импортируйте папку, чтобы увидеть файлы и вложенные каталоги на интерактивном холсте, или создайте собственную карту проекта и вручную добавляйте ветки.

Перемещайтесь по холсту, меняйте масштаб и расположение узлов, изучайте размер файлов и расширения, добавляйте заметки и метки. Проекты сохраняются локально на компьютере; подключение к интернет-сервисам для работы не требуется.

## Как это работает

Создайте проект и добавляйте в него ветки вручную либо выберите папку на компьютере для анализа. При импорте InfiniteWeb показывает дерево каталогов и файлов, а для выбранного узла открывает сведения о его содержимом: вложенности, размерах, расширениях и крупнейших файлах.

Можно перемещать узлы перетаскиванием, менять масштаб холста и переключать автоматическое расположение между деревом и слоями. Изменения проекта сохраняются автоматически. Для каждого проекта также создаётся JSON-файл с деревом и метаданными; открыть папку с этими файлами можно кнопкой **«Расположение»**.

При импорте пропускаются скрытые элементы и типичные служебные папки (например, `node_modules`, `.git`, `build` и `dist`). Импорт ограничен 700 файлами на папку.

## Быстрый старт

### Готовая версия

1. Откройте страницу **Releases** репозитория.
2. Скачайте **InfiniteWeb Setup** для установки или portable-файл для запуска без установки.
3. Запустите приложение.
4. Создайте проект кнопкой **«+»** или импортируйте папку кнопкой **«Импортировать»**.

### Запуск из исходников

```powershell
npm ci
npm start
```

## Как пользоваться

### Создание проекта и веток

1. Нажмите **«+»** рядом со списком проектов.
2. Введите название проекта.
3. Выберите узел на холсте и добавьте дочернюю ветку кнопкой **«Новая ветка»**.
4. Перетащите узлы, чтобы изменить их положение, или выберите **«Перестроить»**, чтобы переключить автоматическую раскладку.
5. Выберите узел, чтобы посмотреть информацию и доступные действия в панели справа.

Корневую ветку проекта удалить нельзя.

### Импорт папки

1. Нажмите **«Импортировать»** на панели слева.
2. Выберите папку для анализа.
3. Дождитесь появления структуры на холсте.
4. Выберите файл или каталог, чтобы посмотреть его сведения. Для файлов и папок также доступны действия по пути, например открыть расположение в Проводнике или скопировать путь.

Скрытые элементы и известные служебные каталоги не импортируются. Если в папке больше 700 файлов, результат может быть ограничен.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `N` | Добавить ветку |
| `I` | Импортировать папку |
| `F` | Вписать структуру в область просмотра |
| `L` | Перестроить расположение узлов |
| `F2` | Переименовать выбранный узел |
| `Del` | Удалить выбранную ветку |
| `Ctrl+Z` | Отменить действие |
| `Ctrl+Y` | Повторить действие |

## Данные и резервные копии

InfiniteWeb автоматически сохраняет проекты и настройки в локальной папке данных приложения Windows. Удаление приложения и удаление пользовательских данных — разные действия: перед очисткой данных приложения сохраните нужные файлы отдельно.

Структурированные JSON-файлы проектов создаются автоматически в подпапке `schemas`. Чтобы открыть её из приложения, нажмите **«Расположение»** на панели слева. Эти файлы можно использовать как резервную копию структуры или обрабатывать отдельно.

## Сборка и релиз

Установите зависимости и соберите установщик Windows вместе с portable-версией:

```powershell
npm ci
npm run build
```

Готовые файлы появятся в папке `release/`. Для создания распакованной версии приложения используйте:

```powershell
npm run pack
```

Проверка приложения:

```powershell
npm run verify
```

GitHub Actions публикует релиз при отправке тега `v*`, совпадающего с версией в `package.json` (например, `v1.0.0`). Перед публикацией workflow устанавливает зависимости, запускает проверку и собирает Windows-установщик и portable-файл.

## Частые вопросы

<details>
<summary><b>Где найти установщик и portable-версию?</b></summary>

В разделе **Releases** репозитория. Установщик называется `InfiniteWeb Setup`, portable-версия — `InfiniteWeb`.

</details>

<details>
<summary><b>Где хранятся проекты?</b></summary>

В локальной папке данных InfiniteWeb в профиле Windows. JSON-файлы со структурой проектов находятся в подпапке `schemas`; открыть её можно кнопкой **«Расположение»** в приложении.

</details>

<details>
<summary><b>Почему импортировались не все файлы?</b></summary>

Скрытые элементы и служебные каталоги пропускаются намеренно. Кроме того, импорт ограничен 700 файлами на папку.

</details>

<details>
<summary><b>Можно ли пользоваться приложением без интернета?</b></summary>

Да. Для просмотра и редактирования локальных проектов подключение к интернету не требуется.

</details>

<details>
<summary><b>Как запустить проверку перед сборкой?</b></summary>

Выполните `npm ci`, затем `npm run verify`. Эта команда запускает встроенную проверку интерфейса приложения.

</details>
